# CDLD: KMLE and EdNet

Code and final numerical results for the KMLE–EdNet representation study.
Repository: https://github.com/dhrim/CDLD_KMLE_EdNet

## Reproduce the paper tables and figures

```bash
python -m pip install -r requirements.txt
python reproduce.py
```

Open **paper_results.ipynb** for the same calculation with visible tables and figures. Outputs are written to `outputs/`.

- Table 1: five-run IRT prediction means, CDLD increments, conditional intervals.
- Table 2: EdNet part log loss, balanced accuracy, macro-F1 and paired contrast.
- Table 3: warm prediction and cold k=40 comparison with the specified noninferiority criterion.
- Figures 1–2: incremental IRT information and cold adaptation curves.
- Supplement: full prediction means, initial IRT comparisons, across-run minima/maxima, response-time sample counts and performance, metadata, tag, CSP and IRT stability results.

`data/` contains final run-level metrics and final inference summaries, not response records. Means and point contrasts are recomputed; confidence limits are taken from the saved paired-bootstrap summaries. This small package reproduces reported numerical summaries and plots without retraining. It does not recompute bootstrap limits from individual predictions.

## Training and analysis implementations

`training/` contains the two final 5×10 training notebooks. They read the original data, construct splits, fit CDLD/Rasch/2PL and save predictions. The first configuration cells specify input filenames, settings and the original dependency versions. Run them from a dedicated writable working directory containing a `data/` directory. Training needs substantial compute and is separate from the quick table reconstruction above.

`code/` contains the final IRT, part, RT, tag, feature-augmentation and SVD/random comparison implementations. Set `CDLD_WORKSPACE` to the root containing the generated training artifacts. The expected artifact layout is documented in `code/README.md`. These scripts require the run-level arrays generated by training; the compact `data/` directory is not a replacement for those arrays.

## Data

Obtain KMLE from its original data source, DOI **10.7910/DVN/PETWZF**, and EdNet-KT1 and questions metadata from **https://github.com/riiid/ednet**. The training notebooks specify the expected filenames. Original response data, individual predictions and model checkpoints are not distributed here. Use the original providers' access and reuse terms.

Only final result reconstruction and scientific implementations are included. Manuscript drafts, review discussions, transfer scripts and intermediate audit reports are excluded.
